Report a problem

If a PDF does not display or edit correctly, open an issue on GitHub or send an email. It helps to include:

  • what you did and what happened instead;
  • your browser and device, for example Chrome on Windows or Safari on an iPhone;
  • if possible, a PDF that shows the problem.

Never send a confidential document. The editor works without uploading your files, and that should stay true when you ask for help. If the problem only happens with a private PDF, describe it, or try to reproduce it with a similar document that contains nothing personal.

Security

To report a security vulnerability, please use GitHub's private reporting rather than a public issue. The security.txt file gives the same details.
