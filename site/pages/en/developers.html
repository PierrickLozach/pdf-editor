PDF Editor for developers

The engine behind this editor, as a JavaScript library: edit text in its original font, redact, recognise text in scans, split, merge, convert, compress and protect PDFs from your own code.

  • Runs where your code runs – in a web page or in Node.js. Documents are never sent to a server, ours or anyone's.
  • Free, no key, no quota – nothing to sign up for. Free under the AGPL-3.0; a commercial licence is available.
  • Same results as the editor – the saved PDF keeps the original's properties and carries no trace of the editing.

Get started

In a web page

<script type="module">
import { PDF } from "{{url}}/lib/v1/pdf-editor.js";

const input = document.querySelector("input[type=file]");
input.onchange = async () => {
  const pdf = await PDF.open(input.files[0]);        // a File, Blob, ArrayBuffer or Uint8Array
  await pdf.replaceAll("2025", "2026");
  const bytes = await pdf.save();                     // Uint8Array
  const url = URL.createObjectURL(new Blob([bytes], { type: "application/pdf" }));
  window.open(url);
};
</script>

The address /lib/v1/ stays compatible for all 1.x versions. The first load downloads the engine (about 10 MB, then cached).

In Node.js (20 or later)

npm install github:PierrickLozach/pdf-editor
import { PDF } from "pdf-editor";
import { writeFile } from "node:fs/promises";

const pdf = await PDF.open("invoice.pdf");            // a path, a Buffer or a Uint8Array
await pdf.redact({ text: "Jane Doe" });               // removed for good, not just covered
await writeFile("invoice-redacted.pdf", await pdf.save());

Examples

Merge, split, reorder

const book = await PDF.merge([cover, chapter1, chapter2]);   // one PDF, in this order
const [intro, rest] = await book.split("1-2, 3-");           // 1-based ranges, one PDF each
await book.movePage(4, 0);                                   // 0-based page numbers
await book.rotatePage(1, 90);
await book.deletePage(2);

Edit text in its original font

const { replaced } = await pdf.replaceAll("Old Company Ltd", "New Company Ltd");

const line = (await pdf.lines(0)).find((l) => l.text.startsWith("Due:"));
await pdf.editLine(0, line.id, "Due: 15 January 2027");
await pdf.addText(0, 72, 700, "Paid", { size: 14, color: "#15803d", bold: true });

Redact for good

await pdf.redact({ text: "1 85 07 75 123 456" });           // every place it appears
await pdf.redact([{ page: 0, box: [72, 100, 300, 140] }]);   // an area, in points from the top-left corner

What is under each box is removed from the file – text, the pixels of pictures, drawings – and a black box is drawn. whiteout() only removes the text and paints over the rest.

Make a scan searchable (OCR)

const scan = await PDF.open(scannedBytes);
const { pages } = await scan.ocr({ languages: ["eng", "fra"] });   // pages that had no text
console.log(await scan.text());

In Node.js, install the recogniser too: npm install tesseract.js. In a browser, the recogniser must be served from your own site (browsers do not let a page start a worker from another site): copy web/vendor/tesseract and web/vendor/tessdata from the repository next to the library and import it from there. Languages: eng fra spa por deu nld ita pol ara heb chi_sim jpn.

Convert, compress, protect

const fromPhotos = await PDF.fromImages([photo1, photo2]);       // JPEG, PNG… one page each
const word = await pdf.toWord();                                  // .docx with the text
const jpegs = await pdf.toImages({ format: "jpg", dpi: 150 });    // [{page, bytes}]
const { before, after } = await pdf.compress("smaller");          // re-encodes heavy photos and scans
const locked = await pdf.protect("a long password");              // AES-256 copy

Reference

Pages are numbered from 0. Positions and sizes are in points (1/72 inch) from the top-left corner of the page. Every method that changes the document can be undone with undo(). Errors are PDFError with a message you can show to people.

MethodWhat it does
PDF.open(input, {password})Open a PDF: Uint8Array, ArrayBuffer, Blob/File; in Node.js also a Buffer or a file path.
PDF.merge([inputs])Several PDFs joined into one.
PDF.fromImages([images], {pageSize})A PDF with one page per picture; pageSize: "a4" (default) or "fit".
pageCount, pagesNumber of pages; [{width, height, rotation}].
text(page?)The text of the document or of one page.
find(text, {matchCase, wholeWord})Every place it appears: [{page, box}].
lines(page)The lines of a page: [{id, text, box, font, size, color, editable}].
replaceAll(find, replacement, options)Replace everywhere in the same font, size and colour → {replaced, skipped}.
editLine(page, id, text, options)Change one line; options size, color, bold, italic.
moveLines(page, ids, dx, dy)Move lines, keeping their exact spacing.
addText(page, x, y, text, options)New text; x, y is the start of the baseline.
addImage(page, box, image)A picture (or a signature with a transparent background) in a box.
whiteout(page, box, color)Remove the text under a box and paint over it.
redact(areas | {text})Remove for good and draw black boxes → {redacted}.
activeContent(), removeActiveContent()Scripts, launch actions, unsafe links, attachments, XFA: list them, remove them.
rotatePage, deletePage, movePage, duplicatePage, insertBlankPage, append(input)Organise pages.
split("1-3, 5" | [[0, 1, 2], [4]])New PDFs from some pages → [Uint8Array]; the document is not changed.
pageNumbers({format, position, start, skipFirst})Number the pages; format like "Page {n} of {total}".
watermark(text, {opacity, color})Semi-transparent text across every page.
compress("smaller" | "smallest")Smaller file → {before, after} in bytes.
ocr({languages, pages, dpi})Make scanned pages searchable → {pages}.
undo(), redo(), canUndo, canRedoHistory of changes.
save()The PDF → Uint8Array.
protect(password, {allowPrint, allowCopy})An encrypted copy (AES-256).
toImages({format, dpi, pages}), toWord(), render(page, scale)Pictures, a .docx, or RGBA pixels for display.
zip([{name, bytes}])A .zip of several files (e.g. the result of split).
