Segnala un problema

Se un PDF non si visualizza o non si modifica correttamente, apri una segnalazione su GitHub o invia un'email. È utile indicare:

  • cosa hai fatto e cosa è successo invece;
  • il tuo browser e il tuo dispositivo, per esempio Chrome su Windows o Safari su un iPhone;
  • se possibile, un PDF che mostra il problema.

Non inviare mai un documento riservato. L'editor funziona senza caricare i tuoi file, e deve restare così anche quando chiedi aiuto. Se il problema si verifica solo con un PDF privato, descrivilo, oppure prova a riprodurlo con un documento simile che non contenga nulla di personale.

Sicurezza

Per segnalare una vulnerabilità di sicurezza, usa la segnalazione privata di GitHub anziché una segnalazione pubblica. Il file security.txt riporta le stesse informazioni.
