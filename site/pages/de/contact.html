Ein Problem melden

Wenn ein PDF nicht richtig angezeigt oder bearbeitet wird, eröffnen Sie ein Issue auf GitHub oder schicken Sie eine E-Mail. Hilfreich sind:

  • was Sie getan haben und was stattdessen passiert ist;
  • Ihr Browser und Ihr Gerät, zum Beispiel Chrome unter Windows oder Safari auf einem iPhone;
  • wenn möglich ein PDF, das das Problem zeigt.

Schicken Sie nie ein vertrauliches Dokument. Der Editor funktioniert, ohne Ihre Dateien hochzuladen, und das soll auch so bleiben, wenn Sie um Hilfe bitten. Wenn das Problem nur bei einem privaten PDF auftritt, beschreiben Sie es oder versuchen Sie, es mit einem ähnlichen Dokument ohne persönliche Inhalte nachzustellen.

Sicherheit

Um eine Sicherheitslücke zu melden, nutzen Sie bitte die private Meldung auf GitHub statt eines öffentlichen Issues. Die Datei security.txt enthält dieselben Angaben.
