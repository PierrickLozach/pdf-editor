Ihre Dokumente

Der Editor läuft vollständig in Ihrem Webbrowser. PDF-Dateien, die Sie öffnen, werden auf Ihrem Gerät gelesen, bearbeitet und gespeichert; sie werden nie an uns oder an Dritte gesendet.

Was Ihr Browser speichert

Damit der Editor gut funktioniert, speichert er einige Dinge im eigenen Speicher Ihres Browsers, ausschließlich auf Ihrem Gerät: das Dokument, das Sie gerade bearbeiten (damit beim Neuladen Ihre Arbeit nicht verloren geht – „Schließen“ entfernt es), die Liste der zuletzt verwendeten Dateien (ein Verweis auf jede Datei auf Ihrem Computer, nie eine Kopie), die Schriften, die Sie hinzufügen oder die er heruntergeladen hat, sowie kleine Einstellungen wie Ihre Sprache. Wir können nichts davon sehen. Sie können diese Daten jederzeit in den Einstellungen Ihres Browsers löschen (Websitedaten).

Word- und LibreOffice-Dokumente

Word- und LibreOffice-Dokumente werden genauso behandelt: Sie werden in Ihrem Browser geöffnet, bearbeitet und gespeichert und nie hochgeladen. Die Textverarbeitung, die der Editor dafür verwendet (EdenText), hat einen KI-Assistenten und eine Diktierfunktion, die Ihren Text oder Ihre Stimme an einen anderen Dienst senden würden: Beide sind auf dieser Website abgeschaltet, und die Sicherheitseinstellungen der Website erlauben ihr keine Verbindung zu einer anderen Website. Die Wörterbücher der Rechtschreibprüfung werden von dieser Website geladen.

Zuletzt verwendete Dokumente stehen in derselben Liste wie PDFs (ein Verweis auf jede Datei, nie eine Kopie). Solange ein Dokument nicht gespeicherte Änderungen hat, behält Ihr Browser eine Kopie davon, die gelöscht wird, sobald Sie es speichern, verwerfen oder schließen. Die Besuchsstatistik zählt nur, dass ein Dokument geöffnet, gespeichert, heruntergeladen oder erstellt wurde, ob es eine Word- oder LibreOffice-Datei ist und das Format eines Downloads.

Kostenlose Schriften

Wenn ein PDF eine kostenlose Schrift verwendet (zum Beispiel von Google Fonts) und die Buchstaben, die Sie eingeben, im PDF fehlen, lädt der Editor diese Schrift aus dem jsDelivr-Netzwerk (cdn.jsdelivr.net) herunter. Wie jeder Download übermittelt diese Anfrage Ihre Netzwerkadresse (IP-Adresse) und den Namen der Schrift an jsDelivr – nie Ihr Dokument. Sie können dies im Fenster „Schriften“ des Editors ausschalten.

Besuchsstatistik

Um zu wissen, wie viel die Website genutzt wird, zählt sie die Besuche selbst – kein Analyseunternehmen ist beteiligt. Wenn eine Seite geöffnet wird, teilt sie unserem Server mit, um welche Seite es sich handelt; bei der ersten Seite eines Besuchs außerdem die Website, von der Sie kommen (nur ihren Domainnamen, zum Beispiel „google“), die Sprache Ihres Browsers und ob Sie einen Computer, ein Tablet oder ein Telefon verwenden. Unser Server ergänzt das Land, das er für die Verbindung erkennt. Im Editor wird außerdem gezählt, dass ein PDF oder ein Dokument geöffnet, gespeichert, heruntergeladen oder erstellt wurde, die Größenklasse eines PDFs, ob ein Dokument eine Word- oder LibreOffice-Datei ist und in welchem Format es heruntergeladen wurde, welche Werkzeuge verwendet wurden und wann die Textverarbeitung neu gestartet werden musste – nie ein Dateiname und nichts aus Ihren Dokumenten.

Gespeichert werden nur Tagessummen (zum Beispiel „Besucher aus Deutschland am 3. März: 12“). Ihre IP-Adresse, ein Cookie oder irgendeine Kennung werden nie gespeichert oder verwendet, sodass ein Besuch weder mit Ihnen noch mit einem anderen Besuch verknüpft werden kann. Es wird nichts gezählt, wenn Ihr Browser Websites bittet, Sie nicht zu verfolgen (Do Not Track oder Global Privacy Control).
