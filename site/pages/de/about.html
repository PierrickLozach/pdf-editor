Über {{name}}

Ein kostenloser Editor, der den vorhandenen Text eines PDFs in der Originalschrift ändert und auch Word- und LibreOffice-Dokumente öffnet, vollständig in Ihrem Browser. Ihre Dokumente verlassen nie Ihr Gerät.

Warum es ihn gibt

Angefangen hat alles mit einer Rechnung und einem falschen Betrag. Die kostenlosen Online-Editoren, die ich ausprobiert habe, wollten entweder, dass ich das Dokument auf ihre Server hochlade, oder sie klebten einfach einen weißen Kasten über die alte Zahl und schrieben die neue darüber, in einer anderen Schrift. Beides ist für eine Rechnung, einen Vertrag, eine Bescheinigung oder einen Arztbrief nicht akzeptabel.

{{name}} wurde gebaut, um genau diese eine Aufgabe richtig zu erledigen: auf ein Wort klicken, tippen und ein PDF erhalten, das aussieht, als wäre es schon immer so gewesen. Daraus wurde dann ein kompletter Werkzeugkasten für alles, was man im Alltag mit PDFs erledigen muss. Heute öffnet er auch Word- und LibreOffice-Dokumente: Derselbe Editor kümmert sich um beide Dateiarten.

Wer ihn macht

Wofür er steht

  • Ihre Dokumente bleiben Ihre. Der ganze Editor läuft in Ihrem Browser, auf Ihrem Computer, Tablet oder Smartphone. Kein Dokument wird hochgeladen, weder zu uns noch zu jemand anderem. Sie können das selbst prüfen: Die Anleitung zum Prüfen eines Online-PDF-Tools zeigt, wie.
  • Änderungen, die man nicht sieht. Der alte Text wird entfernt, nicht versteckt, und der neue Text verwendet die Schrift, Größe und Farbe des PDFs selbst, wann immer das Dokument es zulässt.
  • Kostenlos für den Alltag. Kein Konto, kein Wasserzeichen, keine Begrenzung bei der Zahl der Seiten oder Dokumente.
  • Open Source. Der gesamte Code ist öffentlich auf GitHub unter der AGPL-Lizenz, sodass jeder genau nachlesen kann, was er tut.

Wie er funktioniert

Der Editor basiert auf MuPDF, der PDF-Engine von Artifex, kompiliert zu WebAssembly, damit sie im Browser fast so schnell läuft wie ein installiertes Programm. Die Texterkennung für gescannte Seiten nutzt Tesseract. Die Schriften stammen aus dem PDF selbst, von Ihrem Computer, wenn Sie es erlauben, oder aus kostenlosen Schriften mit offener Lizenz. Die Website wird von Cloudflare gehostet. Jede Änderung wird in Chrome, Firefox und Safari getestet, bevor sie online geht. Word- und LibreOffice-Dokumente werden mit EdenText bearbeitet, einer freien Textverarbeitung von Steffen Becker, die ebenfalls im Browser läuft.
