Text in der Originalschrift ändern, verschieben, ein Datum oder einen Betrag korrigieren, unterschreiben, Seiten neu anordnen. Keine Installation, kein Wasserzeichen – und Ihre Dateien verlassen nie Ihren Computer.

Editor öffnen

In Chrome und Edge schreibt „Speichern“ Ihre Änderungen direkt in Ihre Datei zurück. PDFs bis 250 MB.

Funktioniert in Chrome, Edge, Firefox und Safari, auf Computern, Tablets und Smartphones.

Alles, was Sie zum Korrigieren eines PDFs brauchen

Die alltäglichen Änderungen, richtig gemacht: Der Text, den Sie eingeben, sieht aus wie der Text, der dort stand.

Text wirklich bearbeiten

Klicken Sie auf einen Text und tippen Sie. Die alten Wörter werden entfernt – nicht unter einem weißen Kasten versteckt – und die neuen erhalten dieselbe Schrift, Größe und Farbe.

Text präzise verschieben

Ziehen Sie eine Zeile oder einen ganzen Block: Er rastet an den Rändern und Grundlinien der anderen Zeilen ein, sodass alles ausgerichtet bleibt.

Suchen & Ersetzen

Ändern Sie einen Namen, ein Datum oder einen Betrag überall im Dokument auf einmal, in fettem wie in normalem Text.

Die richtigen Schriften

Der Editor verwendet die Schriften des PDFs, dann die Ihres Computers, dann kostenlose Schriften derselben Familie. Fügen Sie eine Schrift einmal hinzu: Ihr Browser behält sie.

Unterschreiben, abdecken, hinzufügen

Fügen Sie eine Unterschrift oder ein Bild hinzu, setzen Sie Text an beliebiger Stelle, decken Sie ab, was verschwinden soll – der Text darunter wird wirklich entfernt.

Seiten organisieren

Seiten drehen, neu anordnen, duplizieren oder löschen, leere Seiten einfügen und mehrere PDFs zu einem zusammenführen.

Ein kompletter Werkzeugkasten

Alles Weitere im Menü Werkzeuge. Wie alles hier läuft es auf Ihrem Gerät.

Unterschreiben

Zeichnen Sie Ihre Unterschrift mit Maus oder Finger, tippen Sie sie oder nutzen Sie ein Foto davon. Ihr Browser merkt sie sich.

Schwärzen

Schwärzen Sie Namen, Nummern oder ganze Bereiche. Anders als bei einem schwarzen Kasten darüber wird das Darunterliegende endgültig aus der Datei entfernt.

Teilen, zusammenfügen, umwandeln

Seiten extrahieren oder ein PDF teilen, mehrere zusammenfügen, Bilder in ein PDF umwandeln oder ein PDF in Word, Text oder Bilder.

Schützen

Machen Sie einen großen Scan klein genug für E-Mails, nummerieren Sie die Seiten oder setzen Sie „VERTRAULICH“ auf jede Seite.

Zur Dokumentation

Drei Schritte

  1. Öffnen

    Legen Sie ein PDF im Editor ab. Auch passwortgeschützte Dateien funktionieren.

  2. Bearbeiten

    Klicken, um Text zu ändern, ziehen, um ihn zu verschieben, die Werkzeuge für alles andere. Jederzeit widerrufbar.

  3. Speichern

    Laden Sie das bearbeitete PDF herunter. Ihr Original wird nie verändert.

Datenschutz von Grund auf

Die meisten Online-PDF-Editoren laden Ihre Dokumente auf ihre Server hoch. Dieser kann das nicht: Der gesamte Editor läuft in Ihrem Browser.

  • Ihre PDFs werden nur auf Ihrem Gerät geöffnet, bearbeitet und gespeichert – nie hochgeladen.
  • Kein Konto, keine Cookies, keine Werbung, kein Tracking.
  • Nichts über Sie wird auf einem Server gespeichert: Ihre Schriften und Einstellungen bleiben in Ihrem Browser.
  • Kostenlos und Open Source: Jeder kann prüfen, was er tut.

Fragen

Ist es wirklich kostenlos?

Ja. Keine Testversion, kein Wasserzeichen, keine Seitenbegrenzung. Der Editor läuft auf Ihrem Computer, daher kostet sein Angebot fast nichts.

Brauche ich ein Konto?

Nein. Öffnen Sie den Editor und legen Sie ein PDF ab.

Verändert „Speichern“ meine Originaldatei?

In Chrome und Edge ja: „Speichern“ schreibt Ihre Änderungen in das geöffnete PDF, wie jede Desktop-App, und unter „Zuletzt verwendet“ öffnen Sie es mit einem Klick erneut. In Firefox und Safari lädt „Speichern“ das bearbeitete PDF herunter und Ihr Original bleibt unverändert. Widerrufen funktioniert, bis Sie das PDF schließen.

Wie groß darf ein PDF sein?

Bis zu 250 MB. Größere PDFs sind fast immer Scans oder Fotos: Verwenden Sie „Dateigröße reduzieren …“ im Editor oder auf dem Mac Vorschau › Ablage › Exportieren … › Quartz-Filter: Dateigröße reduzieren.

Sehen meine Änderungen aus wie das Original?

Bei den meisten PDFs ja: Der Editor verwendet die Schriften im PDF, dann die Schriften auf Ihrem Computer, dann kostenlose Schriften derselben Familie. Ist ein Buchstabe wirklich nicht verfügbar, nimmt er eine ähnliche Schrift mit derselben Breite und sagt es Ihnen.

Kann ich gescannte Dokumente bearbeiten?

Ein Scan ist ein Bild einer Seite, ohne bearbeitbaren Text. Sie können trotzdem Teile abdecken und Text und Bilder darüber setzen.

Wo werden meine Schriften gespeichert?

In Ihrem Browser, auf diesem Gerät. Sie werden nie irgendwohin gesendet. Fügen Sie nur Schriften hinzu, die Sie verwenden dürfen.
