报告问题

如果某个 PDF 无法正确显示或编辑，请在 GitHub 上提交 issue，或发送电子邮件。最好附上：

  • 您做了什么，实际发生了什么；
  • 您的浏览器和设备，例如 Windows 上的 Chrome 或 iPhone 上的 Safari；
  • 如有可能，附上一个能重现问题的 PDF。

切勿发送机密文档。编辑器无需上传您的文件即可工作，在您寻求帮助时也应如此。如果问题只出现在一个私人 PDF 上，请描述问题，或尝试用一份不含任何个人信息的类似文档来重现。
