关于 {{name}}

一款免费的 PDF 编辑器，能用原字体修改 PDF 中已有的文本，全部在您的浏览器中完成。您的文档绝不会离开您的设备。

为什么会有它

一切始于一张发票上一个写错的金额。我试过的免费在线编辑器，要么要求我把文档上传到它们的服务器，要么只是在旧数字上盖一个白框，再用另一种字体在上面打上新数字。对于发票、合同、证明或医疗信函来说，这两种做法都不可接受。

{{name}} 就是为了把这件事做好而开发的：点击一个词，输入，得到的 PDF 看起来就像一直是这样。后来它逐渐成为一个完整的工具箱，涵盖人们日常处理 PDF 时需要做的各种事情。

它坚持什么

  • 您的文档始终属于您。整个编辑器都在您的浏览器中运行，无论是在电脑、平板还是手机上。任何文档都不会被上传，既不会传给我们，也不会传给其他任何人。您可以亲自验证：检查在线 PDF 工具的指南介绍了方法。
  • 改过却看不出痕迹。旧文本会被删除，而不是被遮住；只要文档允许，新文本就会沿用 PDF 自身的字体、字号和颜色。
  • 日常使用免费。无需账户，没有水印，页数和文档数量都不受限制。
  • 开源。完整代码以 AGPL 许可证公开在 GitHub 上，任何人都可以准确了解它做了什么。

它如何工作

编辑器基于 Artifex 开发的 PDF 引擎 MuPDF，并编译为 WebAssembly，因此能在浏览器中以接近原生程序的速度运行。扫描页面的文字识别使用 Tesseract。字体来自 PDF 本身，或经您允许后来自您的电脑，或来自免费的开放许可字体。网站由 Cloudflare 托管。每次改动在上线前都会在 Chrome、Firefox 和 Safari 中进行测试。
