Caviarder un PDF pour que le texte masqué disparaisse vraiment

Avant de partager un contrat, une fiche de paie ou un compte rendu médical, vous devez parfois cacher un nom, un numéro de compte ou une adresse. Le recouvrir ne suffit pas : il faut le supprimer du fichier.

Pourquoi un rectangle noir ne suffit pas

Dessiner un rectangle noir sur un texte, dans un lecteur PDF ou avant d'imprimer en PDF, ajoute seulement une forme par-dessus. Le texte reste dans le fichier : n'importe qui peut le sélectionner, le copier ou le retrouver par une recherche. Des informations confidentielles ont fuité de nombreuses fois exactement de cette façon.

Un vrai caviardage supprime le contenu lui-même, les lettres, les parties d'images et les dessins situés sous la zone marquée, puis dessine le rectangle noir à leur place.

Étape par étape

  1. Ouvrez l'éditeur et ouvrez le PDF.
  2. Cliquez sur Outils, puis sur Caviarder. Une barre apparaît en haut de la page.
  3. Marquez ce qui doit disparaître : tracez un cadre sur une zone, ou tapez un mot ou un nombre dans la barre pour le marquer partout dans le document.
  4. Vérifiez les zones marquées. Cliquez sur une marque pour la retirer si vous en avez trop marqué.
  5. Cliquez sur Appliquer le caviardage. Le texte, les images et les dessins sous les marques sont supprimés pour de bon ; enregistrez ensuite le PDF.

Vous pouvez encore annuler tant que le PDF est ouvert. Dans le fichier enregistré, le contenu a disparu, pour tous les lecteurs et tous les logiciels.

Masquer ou caviarder ?

Masquer supprime le texte sous le rectangle blanc mais laisse les images et les dessins dans le fichier, simplement recouverts. Il sert aux corrections, par exemple effacer une ligne avant d'en écrire une nouvelle. Caviarder supprime tout ce qui se trouve sous la marque, images comprises, et laisse un rectangle noir visible. Pour tout ce qui est confidentiel, utilisez Caviarder.

Vérifier avant de partager

  • Ouvrez le PDF enregistré dans un autre lecteur et cherchez les mots supprimés. Rien ne doit être trouvé.
  • Sélectionnez le texte autour du rectangle noir et collez-le ailleurs : la partie supprimée ne doit pas apparaître.
  • Regardez les propriétés du document (titre, auteur, sujet) dans votre lecteur PDF. Le caviardage ne les modifie pas ; si elles contiennent un nom, corrigez-le à la source.
  • Les fichiers joints au PDF ne sont pas couverts par les rectangles noirs. Si le PDF en contient, l'éditeur vous le signale à l'ouverture et les retire à l'enregistrement, sauf si vous choisissez de les garder.
