Signaler un problème

Si un PDF ne s'affiche pas ou ne se modifie pas correctement, ouvrez un ticket sur GitHub ou envoyez un e-mail. Il est utile de préciser :

  • ce que vous avez fait et ce qui s'est passé à la place ;
  • votre navigateur et votre appareil, par exemple Chrome sous Windows ou Safari sur un iPhone ;
  • si possible, un PDF qui montre le problème.

N'envoyez jamais de document confidentiel. L'éditeur fonctionne sans envoyer vos fichiers, et cela doit rester vrai quand vous demandez de l'aide. Si le problème n'apparaît qu'avec un PDF privé, décrivez-le, ou essayez de le reproduire avec un document semblable qui ne contient rien de personnel.

Sécurité

Pour signaler une faille de sécurité, utilisez le signalement privé de GitHub plutôt qu'un ticket public. Le fichier security.txt donne les mêmes informations.
