どんな PDF もブラウザで編集。無料です。

元のフォントのままテキストを変更・移動し、日付や金額を修正し、署名し、ページを並べ替えられます。インストール不要、透かしなし。ファイルがコンピュータの外に出ることもありません。

エディタを開く

Chrome と Edge では、「保存」で変更内容が元のファイルに直接書き込まれます。250 MB までの PDF に対応しています。

パソコン、タブレット、スマートフォンの Chrome、Edge、Firefox、Safari で使えます。

PDF の修正に必要なものがすべて

日常の編集をきれいに。入力したテキストは、元のテキストと同じ見た目になります。

本当にテキストを編集

テキストをクリックして入力するだけです。古い文字は白い四角で隠すのではなく実際に削除され、新しい文字には同じフォント、サイズ、色が使われます。

テキストを正確に移動

1 行またはブロック全体をドラッグすると、ほかの行の端やベースラインに吸着するので、すべてがきれいに揃います。

検索と置換

名前、日付、金額を文書全体で一度に変更できます。太字のテキストも標準のテキストも同じように扱えます。

正しいフォント

エディタはまず PDF 自体のフォントを使い、次にコンピュータのフォント、さらに同じファミリーの無料フォントを使います。フォントは一度追加すれば、ブラウザに保存されます。

署名、白塗り、追加

署名や画像を追加し、好きな場所にテキストを追加し、消したい部分を白塗りできます。その下のテキストは実際に削除されます。

ページを整理

ページの回転、並べ替え、複製、削除、空白ページの挿入、複数の PDF の結合ができます。

充実のツール

そのほかの機能は「ツール」メニューにあります。ここにあるすべてと同様に、お使いのデバイス上で動作します。

署名

マウスや指で署名を手書きしたり、名前を入力したり、署名の写真を使ったりできます。ブラウザが次回のために記憶します。

墨消し

氏名や番号、領域全体を黒く塗りつぶします。上から黒い四角を重ねるのとは違い、下にある内容はファイルから完全に削除されます。

スキャンを検索可能に

12 言語の文字認識（OCR）で、スキャンした文書を検索・コピーできる文書に変えます。

分割・結合・変換

ページの抽出や PDF の分割、複数の PDF の結合、画像から PDF への変換、PDF から Word・テキスト・画像への変換ができます。

パスワード保護

パスワード（AES-256 暗号化）を設定し、パスワードを知っている人だけが PDF を開けるようにします。

圧縮・ページ番号・透かし

重いスキャンをメールで送れるサイズに圧縮したり、ページ番号を付けたり、すべてのページに「社外秘」と入れたりできます。

よくある質問

本当に無料ですか？

はい、日常の編集は無料です。試用期間も透かしもページ数の制限もアカウントもありません。エディタはお使いのコンピュータ上で動くため、提供にかかる費用はほとんどありません。任意の Pro 機能（一括処理、スマート黒塗り、OCR 無制限、PDF の比較、フォーム）は有料です。

Pro では何が使えますか？

一括処理、個人データの自動黒塗り、ページ数の制限がない文字認識、2 つの PDF の比較、フォームです。無料のエディタと同じく、ファイルはお使いのコンピュータに残ります。ライセンスは同時に 1 台のコンピュータで使えます。Pro のウィンドウから別のコンピュータに移すこともできます。

アカウントは必要ですか？

いいえ。エディタを開いて PDF をドロップするだけです。

「保存」すると元のファイルは変更されますか？

Chrome と Edge では、はい。一般的なデスクトップアプリと同じように、「保存」で開いた PDF に変更が書き込まれ、「最近使ったファイル」からワンクリックで開き直せます。Firefox と Safari では、「保存」で編集した PDF がダウンロードされ、元のファイルはそのまま残ります。PDF を閉じるまでは取り消しができます。

PDF の大きさに上限はありますか？

250 MB までです。それより大きい PDF のほとんどはスキャンや写真です。エディタの「ファイルサイズを縮小…」を使うか、Mac では「プレビュー › ファイル › 書き出す…」で Quartz フィルタに「ファイルサイズを減らす」を選んでください。

編集した部分は元と同じ見た目になりますか？

ほとんどの PDF では、はい。エディタはまず PDF 内のフォントを使い、次にコンピュータのフォント、さらに同じファミリーの無料フォントを使います。どうしても使えない文字があるときは、同じ幅の類似フォントを使い、そのことをお知らせします。

スキャンした文書も編集できますか？

スキャンはページを撮った画像なので、編集できるテキストがありません。それでも、一部を白塗りしたり、上にテキストや画像を追加したりできます。

フォントはどこに保存されますか？

このデバイスのブラウザ内です。どこかに送信されることはありません。使用が許可されているフォントだけを追加してください。

いつでも始められます

インストールは不要です。PDF を開いて編集を始めましょう。
