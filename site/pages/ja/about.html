{{name}} について

PDF にもともと書かれているテキストを元のフォントのまま変更でき、Word や LibreOffice の文書も開ける無料のエディタです。すべてブラウザ内で動き、文書がデバイスの外に出ることはありません。

生まれた理由

きっかけは、1 枚の請求書と、間違った 1 つの金額でした。私が試した無料のオンラインエディタは、文書をサーバーにアップロードさせるものか、古い数字の上に白い四角を貼り、その上に別のフォントで新しい数字を書くだけのものばかりでした。請求書、契約書、証明書、医療関係の書類では、どちらも受け入れられません。

{{name}} は、その 1 つの作業をきちんとこなすために作りました。単語をクリックして入力するだけで、最初からそうだったかのように見える PDF ができあがります。その後、PDF でよく行う日常の作業のための充実したツールへと成長しました。 今では Word や LibreOffice の文書も開けるので、同じエディタで両方のファイルを扱えます。

大切にしていること

  • 文書はあなたのものです。エディタはすべてブラウザ内で、お使いのパソコン、タブレット、スマートフォン上で動作します。文書が私やほかの誰かにアップロードされることはありません。ご自身で確かめることもできます。方法はオンライン PDF ツールの確認方法のガイドで説明しています。
  • 編集したとわからない仕上がり。古いテキストは隠すのではなく削除され、文書が許す限り、新しいテキストには PDF 自体のフォント、サイズ、色が使われます。
  • 日常の利用は無料。アカウント不要、透かしなし、ページ数や文書数の制限もありません。
  • オープンソース。すべてのコードを AGPL ライセンスで GitHub に公開しているので、何をしているのか誰でも正確に確認できます。

仕組み

エディタは、Artifex が開発した PDF エンジン MuPDF を土台にしています。MuPDF を WebAssembly にコンパイルしているため、ブラウザ内でもネイティブに近い速度で動作します。スキャンしたページの文字認識には Tesseract を使っています。フォントは PDF 自体から、許可があればお使いのコンピュータから、または無料のオープンライセンスのフォントから取得します。サイトは Cloudflare でホストしています。すべての変更は、公開前に Chrome、Firefox、Safari でテストしています。 Word と LibreOffice の文書は、Steffen Becker によるフリーのワープロ EdenText で編集します。こちらもブラウザ内で動きます。
