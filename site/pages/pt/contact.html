Relatar um problema

Se um PDF não aparece ou não é editado corretamente, abra uma issue no GitHub ou envie um e-mail. Ajuda informar:

  • o que você fez e o que aconteceu no lugar;
  • seu navegador e seu dispositivo, por exemplo Chrome no Windows ou Safari num iPhone;
  • se possível, um PDF que mostre o problema.

Nunca envie um documento confidencial. O editor funciona sem enviar seus arquivos, e isso deve continuar valendo quando você pede ajuda. Se o problema só acontece com um PDF particular, descreva-o ou tente reproduzi-lo com um documento parecido que não tenha nada pessoal.

Segurança

Para relatar uma vulnerabilidade de segurança, use o relato privado do GitHub em vez de uma issue pública. O arquivo security.txt traz as mesmas informações.
